# Términos de Boxly y acuerdo de tratamiento de datos

## Qué es Boxly

Boxly es un sistema para llevar el taller: clientes, vehículos, órdenes de trabajo, repuestos, turnos y cobros. Lo usa el taller y sus clientes.

## Quién responde por los datos

Cada taller es **responsable** de los datos de sus clientes (nombre, DNI, teléfono, correo, patentes, órdenes y pagos). Boxly es el **encargado del tratamiento**: guarda y procesa esos datos solo para prestarle el servicio al taller, de acuerdo con la Ley 25.326 de protección de datos personales.

## Para qué usamos los datos

Con una única finalidad: prestar el servicio. Los datos del taller y de sus clientes se usan para operar el sistema (turnos, órdenes, stock, cobros y avisos) y para dar soporte cuando el taller lo pide. No los vendemos ni los usamos para publicidad.

## Confidencialidad y seguridad

Boxly cuida los datos con medidas razonables: contraseñas cifradas, sesiones que vencen, registro de las acciones que modifican datos y copias de seguridad.

Boxly **no entra a ver los datos del taller** salvo que el taller lo autorice con un **acceso de soporte**: es temporal, de solo lectura, queda registrado y el taller puede cortarlo cuando quiera.

## Derechos de las personas

Las personas cuyos datos están en Boxly pueden pedir **acceso, rectificación y supresión** de sus datos. El taller responde esas solicitudes y Boxly lo ayuda a cumplirlas desde el sistema.

## Si te vas de Boxly

El taller puede descargar un **respaldo completo** de sus datos en cualquier momento. Al dar de baja la cuenta, los datos del taller se eliminan de forma segura, salvo lo que la ley obligue a conservar.

## Contacto

Para consultas sobre estos términos o sobre el tratamiento de datos, escribinos al correo de soporte de Boxly que figura en tu cuenta.
