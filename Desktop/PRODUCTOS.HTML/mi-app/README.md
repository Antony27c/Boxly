# 🛒 Mi Aplicación Multifuncional

Aplicación web con tres módulos principales: gestión de productos, lista de tareas y consumo de API externa.

![Captura principal]"assets\screnshot2\Captura de pantalla 2026-04-30 153118.png"
 
## 🚀 Funcionalidades

### 1. **Página de Productos** (`productos.html`)
- CRUD completo de productos (Crear, Leer, Actualizar, Eliminar)
- Filtrado por categorías
- Almacenamiento local con `localStorage`
- Diseño responsive con Tailwind CSS

![Productos](assets/screenshots/products.png)

### 2. **Lista de Tareas** (`todo.html`)
- Agregar/marcar/eliminar tareas
- Contador de tareas pendientes
- Persistencia de datos en el navegador
- Efectos visuales con CSS transitions

![To-Do](assets/screenshots/todo.png)

### 3. **API Demo** (`api-demo.html`)
- Consumo de [JSONPlaceholder API] https://pokeapi.co/api/v2/pokemon?limit=20
- Fetch para obtener posts de ejemplo
- Visualización en cards interactivas
- Manejo de estados de carga/error

![API Demo](assets/screenshots/api.png)

## 🛠 Tecnologías Usadas
- **Frontend**:
  - HTML5 semántico
  - CSS3 (Tailwind + custom styles)
  - JavaScript ES6+
  - Fetch API
- **Herramientas**:
  - Git/GitHub
  - VS Code
  - Live Server
